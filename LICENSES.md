# Software de terceros

## pdf-inspector

MIT © Firecrawl — https://github.com/firecrawl/pdf-inspector

Se instala vía pip (`pdf-inspector`), no se vendoriza. Se usa para dos cosas:
clasificar el PDF (`process_pdf`) y extraer texto posicionado
(`extract_text_with_positions`).

## Dependencias instaladas por pip

lxml (BSD), openpyxl (MIT), pdfplumber (MIT), pypdfium2 (Apache-2.0 / BSD-3),
pytesseract (Apache-2.0). Tesseract OCR es un binario del sistema (Apache-2.0).
